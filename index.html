CONFIGURATION

Connecter
Spotify.

Pour activer la recherche, crée une application dans le tableau de bord Spotify for Developers. Copie son Client ID ci-dessous et ajoute l'URL de cette page comme Redirect URI.

Étapes :
1. Ouvre developer.spotify.com/dashboard
2. Crée une app pour la Web API.
3. Dans ses réglages, ajoute l'URL exacte affichée ici aux Redirect URIs.
4. Copie le Client ID, enregistre, puis connecte-toi.

Ne partage jamais de mot de passe ou de Client Secret. Cette page utilise PKCE.
